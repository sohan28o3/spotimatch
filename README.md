# Spotimatch

A Next.js app with Google sign-in, editable profiles, and three optional onboarding steps: favorite artists/tracks/albums, Last.fm connection, and Spotify history import. Users can revisit every source after onboarding.

Run `npm install` then `npm run dev`. Firebase credentials are required to sign in and use the app.

See [SETUP.md](SETUP.md) for Firebase, Last.fm, environment variables, Firestore rules, free hosting and integration checks.

Validation: `npm run lint`, `npm test`, `npm run build`.
